## 🌊 About the Project

PRAN (Predictive Rescue & Assistance Network) is a proposed AI-assisted emergency response system designed to improve rescue coordination during floods and other disaster situations.

During floods, emergency teams may receive multiple SOS requests simultaneously. Identifying which people need immediate assistance can become challenging.

PRAN aims to address this problem by analyzing emergency requests, prioritizing cases based on urgency, and supporting responders with location-based rescue coordination.

## 🎯 Problem Statement

During flood emergencies:
- Multiple SOS requests can arrive simultaneously.
- Rescue teams may struggle to identify the most urgent cases.
- Limited emergency resources need better prioritization.
- Responders need location information and safer route guidance.
- Tracking rescue progress can be difficult.

## 💡 Proposed Solution

PRAN introduces an AI-assisted prioritization and rescue coordination workflow.

The system aims to:
1. Receive emergency SOS requests.
2. Analyze urgency and severity.
3. Prioritize people requiring immediate assistance.
4. Help responders identify suitable rescue assignments.
5. Support location-based route visualization.
6. Track rescue progress and request status.

## ⭐ Key Features

- **SOS Emergency Requests:** Collects emergency assistance requests.
- **AI-Assisted Prioritization:** Helps rank requests according to urgency.
- **Flood Risk Visualization:** Displays geographical information through a map interface.
- **Responder Coordination:** Supports rescue assignment and coordination.
- **Route Visualization:** Helps visualize possible rescue routes.
- **Rescue Status Tracking:** Supports tracking pending and rescued requests.

## 🔄 Project Workflow

SOS Request → Priority Analysis → Emergency Dashboard → Responder Assignment → Route Visualization → Rescue Status Update

## 🛠️ Technology Stack

The prototype is based on a web application approach.

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Mapping: Leaflet and OpenStreetMap
- AI-assisted prioritization: Prototype scoring and analysis
